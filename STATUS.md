# MAKERMAKER: status and technical notes

What is built, how, and what is planned. For users: [README.md](README.md). Goals and decisions: [GOAL.md](GOAL.md); terms: [CAD_DEFINITIONS.md](CAD_DEFINITIONS.md).

## Develop

```sh
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests incl. geometry kernel in Node
npm run build      # typecheck + production build into dist/
npm run preview    # serve dist/ (service worker active, works offline after first load)
```

Chromium-based browsers only.

## Layout

- `src/doc` – document model (plain immutable data), expressions with units, undo history
- `src/kernel` – Replicad/OpenCascade build of bodies, runs in a Web Worker
- `src/viewer` – three.js viewport
- `src/ui` – panels
- `src/io` – `.mmk` design file (ZIP: `document.json` + `history/`), file access
- `public/sw.js` – offline cache

## Status

- Bodies are recipes of extrude steps: each has a sketch plane (ground / front / right plane with offset, or the top face of an earlier step), one or more profiles (rectangle with corner radius, circle, regular polygon, polygon) or picked areas, a depth, how far it also reaches behind its plane (back) and add / cut (cut: blind or through). Features run in order, except fillets/chamfers: unbaked they run last, so they also round or chamfer edges of later cuts (their edges draw light grey). Bake (button on the card) keeps one where it is: later cuts go through it (hatched card, dark edges). Click a fillet/chamfer face to pick that part (double-click: the whole finish); Del leaves that edge out (Restore on the card brings it back) or deletes the whole finish.
- Sketch mode: New sketch (S or the toolbar's first tool) picks a top face or empty space, turns the camera to it and shows a grid; leaving the first pull of a direct shape flat (click or Esc) also enters it; Draw on a selected sketch reopens it. In sketch mode R / C / P draw flat into the sketch and the tool goes on; Esc stops the tool, Esc again or ✓ leaves. E in sketch mode turns a flat view to an angled one with its selected shapes, or all of them, picked (see Extrude below), the sketch's areas shown faintly. Areas: overlapping shapes split into pieces, computed exactly by the kernel; where lines take part, the faces they enclose with the shapes they reach: ends sticking out are ignored, a line across splits a face, curves there become fine polylines, see `src/doc/arrangement.ts`; an extrusion stays linked to its areas (stored as inside / outside shapes, or for line faces as a point inside, so they follow shape edits). E on a sketch with lines pulls all its areas.
- Drawing modes (`MODES` in src/viewer/sketch.ts): rectangle: two corners, from the centre, turned (a side's two ends, then its width), turned from the centre (its middle, a point it points to, then its size; Alt: ⇄ turned); circle: centre and radius, two points across, through three points, tangent to two lines (click both, then where it lies: its size; typed: its radius, R); regular polygon: centre to a corner, centre to a side's middle, one side end to end (the polygon to its left). Alt (Shift Alt: back) steps to the next mode: before drawing it is kept for the shapes to come, while drawing it is for that shape only (its first point stays); so does the tool's key or toolbar button pressed again (kept). A only splits lines for snapping. The mode is remembered this session; a switch shows its pictogram and name top left in the view for a second; the hint names the mode.
- Direct tools: R rectangle, C circle (cylinder), N regular polygon (diameter, Tab: number of sides; the first corner points at the pointer), P polygon (Esc leaves it open), L line (a single line, two clicks; hold ⌘ (else Ctrl) after one: the next from its end; a line extrudes only as the edge of a face lines enclose), O sphere (drag from its centre on a face or the ground). Shapes keep their meaning (a hexagon stays a regular polygon with 6 sides). Drawing tools and Extrude stay on after each shape or pull until Esc; one-shot actions (look at face and the like) end by themselves.
- Bodies have a colour (picker in the body panel, swatch in the list; new bodies get one from a palette) and an eye to show / hide them like sketches (Shift-click another eye in the same list: every row between, both included, goes the way the first click went; in sketch mode the same for see-through / fully shown); hidden bodies are still built but not drawn, picked or snapped to.
- Snapping while drawing: corners and line ends, centres, the middles of sides and straight edges, circle quadrants, crossings of sketch lines, circles and body edges, then along lines and edges, else on the zoom's step; only geometry in the plane drawn on. A sketch takes the pointer when it is over one of its shapes or near an outline; empty space draws on the ground unless it is seen almost edge-on. A note next to the pointer says what it snaps to (along a side with the lengths on both sides); the shape, line or edges it belongs to light up. With the pointer on a line, A adds an evenly spaced snap point along it (around a circle: one more than the 4 quadrants), Shift A removes one; while changing, all its points show.
- Lines that close a loop (the new line's ends meet other lines' ends, within 0.001 mm, either way round) become one polygon, which extrudes like any shape.
- Line tool: holding ⌘ (else Ctrl) after a line starts the next one at its end at once, shown, snapped and typed into like the first (it stays when ⌘ is let go, to type; Esc drops it; ⌘ as part of a shortcut like ⌘Z does not start it); a click still holding ⌘ goes on from the new end.
- The angle counts from the previous line (going straight on is 0°: the next polygon side, a line on from the last with ⌘), else from the plane's x axis; B with the pointer on a straight line, edge or guide counts it from that line instead (again, or off a line: from the x axis); the hint shows on a line.
- Lines and polygon sides are drawn as angle and length from the last corner: the angle turns in 1° steps (Ctrl: the minimum angle, Settings → General, default 0.01°; Shift: the angle step, default 45°, A finer, Shift A coarser, through 90, 45, 30, 15, 10, 5, 1°, set before pressing Shift; rays around the last corner preview its directions), the length on the zoom's step (Ctrl: the minimum step). A snap point or line sets the end exactly (with Shift, or a typed angle, its distance along that angle). The pointer's note shows the length (L) first; the angle (∠) is labelled inside the angle, between a faint ray along the plane's x axis and the side with an arc between them, as close as it stays clear of the other labels, the lines, the pointer and its note and the view's controls, else just outside the angle: typing a digit starts the length, Tab switches to the angle, a typed value stays while the pointer sets the other, click or Enter sets the corner.
- Modifiers, one meaning each (`MODS` in src/ui/keys.ts, listed in Settings → Hotkeys). At a click: Shift adds to the selection or takes away (lists: a range), ⌘ (else Ctrl) adds one in lists, isolates on an eye and goes on with the line tool, Alt picks faces and edges. While moving (drags, handles, pulls, scrubbing a field, arrow keys): no key moves in steps that follow the zoom (a power law rounded to 1-2-5: about 1 mm at a normal zoom, 0.5 m with 20 m across the view; arrows 1 mm), Shift constrains (square, proportions, 15° turns) and takes ten times bigger steps, Ctrl moves in the minimum step (Settings → General, default 0.01 mm; turns 0.1°), Alt draws and resizes from the centre; they combine. Turns default to 1°.
- Faces and edges: hold Alt to light the edge near the pointer (within 6 px, not behind a face) or else the face under it; Alt-click selects its body and picks that part (on a fillet's or chamfer's face: that part of the finish instead, as a plain click; pressed again (Alt still held or not) its size drags; Del leaves its edge out, its last picked edge: the whole finish, never the body; Del with faces or edges picked deletes nothing and says so) (Shift + Alt adds more faces (on any bodies) or edges of that body, or takes one away; picked parts are blue, the Alt preview orange; choosing in the list starts over) (a face: E pulls it, S sketches on it); a double right-click or Alt double-click near an edge picks its tangent chain (a straight edge between sharp corners, as a box's: the loop around the face under the pointer) (a plain double-click does not; the double press is counted by the app, as a Mac sends no dblclick for Ctrl- or right-clicks): the edges joined end to end where they run on smoothly (within 30°, as edges are drawn as segments): a circle's halves, a hole's rim, a rounded outline. Picked edges show their length, how many, and Ø when they form one circle.
- Info panel (bottom of the right column): a picked edge's length or face's area; one sketch shape's size or Ø and area (a line: its length), several shapes: their count; bodies: box size as L / W / H (hovering one draws it along the box edge in the view), one body's position (hovering it marks the point) and turn, volume and surface area (from the shown triangles, so curved parts are a hair off; areas and volumes one unit up: mm files show cm² and cm³). On a Mac ⌘ adds to or removes from the selection.
- M (or the move button in the toolbar, beside Extrude and Boolean): the X / Y / Z fields below, all three at once, each starting at 0 (Duplicate: 5, 5, 0 mm; selected: typing replaces it), the cursor in X (Tab to the next).
- While the move fields are open the move gizmo (the axis wheel) sits at the middle of the selection and follows the preview; a press on it starts the same move as grabbing a body (dead zone, the axis by the drag's direction, the zoom's step: Shift ×10, Ctrl the minimum step) and writes the distance into that axis' field; the field's axis is shown strong; Enter moves, Esc cancels.
- X / Y / Z: a field at the pointer takes a distance (expressions and units, `-100` too); X / Y / Z in it add that axis' field (always in X Y Z order) or go back to it, each keeping its value (typed instead in the middle of a name, or where a parameter starting with that letter could begin: Tab completes it); while typing, the selection shows moved and a translucent copy stays where it was; turning the view meanwhile (drag, cube, wheel) keeps the field, and a click in the view does not select; To object (button, or T in a field unless a parameter name starts there): click a corner, edge or face (the point it reaches is marked while aiming, the pointer's note says what it is: corner, centre, 1/2 of an edge, on edge, on face, and the selection already shows moved there; off any object the value from before), the selection moves along the field's axis until its nearest side reaches it; Enter moves by all of them the selection that far along that axis (bodies; shapes within their sketch plane, the selected ones or all of the selected sketch; across its plane the whole sketch, selected shapes or not, shown live with the bodies extruded from it: a base-plane sketch by its offset, one extruded into a body together with that body, a free plane itself, a sketch on a face with no body of its own leaves the face onto a fixed plane; grey ghosts show where they were), Esc cancels.
- Tab / Shift Tab: select the next / previous body under the pointer (while typing a size Tab switches the side).
- Parameter names complete in every value field: the rest of a matching name shows in grey after the cursor, Tab writes it out with a space. A calculation shows its result in grey after the text (`2*ply` → `= 8 mm`; turns in degrees).
- Renaming: click the name of the selected row in the object or sketch list to edit it in place (the first click selects, or enters the sketch) (Enter or clicking away saves, Esc keeps the old name).
- Guide lines: while drawing, hovering a straight line or edge for a moment (Settings → General → Guide delay, default 333 ms) adds an endless dashed guide along it (magenta; an edge off the plane is projected onto it). Resting on a corner, a line end or a centre gives two guides through it, along the plane's X and Y. The top, bottom and sides of circles, round body edges (cylinders) and spheres give one too, along the plane's axes, snapped to like any line, crossings included. One per direction: a parallel line's guide replaces it, other directions add theirs. A click drops them; G on a guide keeps it (thicker) until G again or sketch mode ends.
- Sketch groups (what was "sketches"; schema 11): a sketch group holds shapes on one plane, in nested sub-groups (`groups` on the sketch, `group` on each shape). In sketch mode the rest fades: bodies turn see-through (still hiding each other: their depth is drawn first) and are not picked, their eyes show it and switch a body back to fully shown (and again to see-through), other sketch groups' shapes and shapes outside the open sub-group turn faint. A breadcrumb under Ortho | Persp shows the way down (`Plate outline › Group 1`); clicking a part goes back up there, Esc goes up one level (at the top: leaves). Clicking a shape in a sub-group that is not open picks the whole sub-group; double-clicking a shape opens its sketch group down to its sub-group. ⌘G (or the group tool) puts the selected shapes and whole sub-groups into a new sub-group of the open one; ⇧⌘G dissolves a selected sub-group. The sketch panel lists sub-groups as foldable rows (a row picks all its shapes).
- Construction lines: any shape can be switched to a construction line and back (the Construction checkbox on its row in the sketch panel, or Q with it selected): drawn dashed, snapped to, never extruded (linked extrusions drop them). The next shapes are drawn as the last one switched (Q alone toggles it); construction shapes stay flat, no pull.
- To object snaps to the nearest point within 10 px: body corners, sphere centres and centres of round edges (a cylinder's top), every sketch snap point (centres, corners, side middles, circle quadrants) and points along straight edges; A / Shift A on a line or circle split it finer or coarser while aiming, as when drawing.
- To object (T, or the target button joined to the field it fills, "T: to object" on hover; in size labels the target and a T): a click's value goes into the field or the typed size where the cursor is, to calculate on with it (`22mm/2`), Enter keeps it; Esc while aiming ends only the aiming. It works in pulls (drawn shapes, picked areas, faces; for the depth or, after Tab, the back, also after typing), while drawing a rectangle, circle, polygon or ball (the size being typed: a width or height from the first corner, a diameter from the centre; off bodies on the sketch's plane), in the move fields, the Cut tool's offset, the Rotate tool (two clicks: where something is now, where it should go: their angle), a joint's Min and Max, and in the panels' body position and group origin X / Y / Z (the origin there), a section's offset and a sketch's or own shapes' plane offset (the plane through the point). Typed in the middle of a name, or where a parameter starting with t could begin, T stays a letter.
- A pull's size is labelled by the axis it goes along (Z on the ground, X or Y on a side face; Depth on a slanted one).
- Extrude (E, `src/viewer/extrude.ts`): what is selected starts picked and waits for Enter (more can be picked first): faces picked with Alt-click (Shift-Alt: more, on any bodies), a sketch's selected shapes or all of them (in sketch mode too; shapes inside others an even number of times stay out: holes), the face last clicked on a selected body. It picks: faces of extrusions and areas of any shown sketch, mixed (hovering lights what a click picks: blue; picked: orange). A plain first click with nothing picked pulls it at once (a fillet or chamfer: drags its size instead); Shift / ⌘-click picks and waits (again: drops it), double-click everything inside the smallest shape there, a shape's outline all inside it, a sketch in the list its shapes (inner ones holes); "Hit Enter" at the pointer, Enter or E pulls them all by one distance (one undo step): each sketch's areas into new bodies along its normal, each face pushes or pulls its extrusion live; the pull goes along the first picked sketch (else face), a flat view along it turns angled only then. Esc while pulling: faces back, picking again; Esc again stops; the tool stays on after each pull.
- Push / pull faces: the face follows the mouse; Esc puts it back. Any other flat face (a revolve's, loft's, imported one's, a cut face …) gets a Push / pull step of its own (`push` in src/kernel/build.ts: the face extruded along its normal and glued on, or cut in; its card: Distance). An end face changes the extrusion's depth; a side face moves that side of its shape (a rectangle side alone, circles and regular polygons grow evenly, polygon sides move both corners), in the linked sketch if there is one. Faces cut by a tool body move that tool body's shape. A face pushed past the opposite one goes on through it: the body then lies beyond that face (an end face: the depth turns negative; a side: the shape flips over to the other side, sizes stay positive). Expressions stay: `ply` → `ply + 6`.
- Two toolbars: the left one makes things (New sketch, the shapes, Sphere, Work plane; then Group / Ungroup, Duplicate, Delete; in sketch mode the shapes), the edit bar above the 3D view edits them (Extrude, Revolve, Sweep, Loft; Boolean, Cut, Offset / Shell, Mirror, Thread; Move, Rotate, Align, Joint; in sketch mode Extrude, Mirror, Offset, Leave). Their menus open below the edit bar.
- Cut tool (edit bar; its icon two boxes split by a dotted line): a body (selected, or clicked next; outlined), then a face or empty space (a straight cut on that face's plane, or on the base plane facing you) or the outline of a sketch line or shape (lit on hover; cut straight through along its sketch's normal, linked: editing the line moves the cut; a closed shape cuts out its inside), or another body that is a ball or a cylinder (one circle pulled; cut along its surface: A inside, B outside; its place, length and Ø copied, the Offset grows or shrinks its radius, T to a point; shown red and see-through). The cut shows as it will be: the body becomes chunk A (into the body from the face, a line's left, a shape's inside), a copy chunk B (the other side, its own colour, named "… B"), the one to be deleted see-through red like the cutting surface, and the cutting surface red and half see-through, a bit larger than the body (a line as a band through it); chunk B is not listed until the cut is kept. A panel centred at the top of the view (below the view cube where it would reach it) has the Offset (from 0, the cursor in it; a line moves to its left; T or To object: the cut goes through the point clicked, shown while aiming), a plane's Turn ° around its axis, drawn dashed red (none set: the plane's own line through its point, so it tilts in place; Set axis: click a straight edge or sketch line or side to turn around it, or a round edge or sketch circle to turn around its centre, named at the pointer while hovering; Esc keeps the axis), each field scrubbed by dragging its label sideways, live, and what stays, one selector of three: Delete A, Delete B (first), Keep both. ✓ or Enter keeps it (one undo step), Esc leaves the body as it was. Each chunk keeps its Cut step (side A / B, offset and turn editable in its card). The sample has a block "Cut me" with a zig-zag line "Cut line" under it.
- Align (edit bar, beside Rotate, as in incase): the selected bodies, groups (each as one) and whole sketches by their boxes in the world: X / Y / Z min, middle or max onto that of all of them, distribute along an axis (equal gaps, the outermost stay; 3 or more), or middles onto the first one's. A whole sketch moves its shapes along its plane and a base plane's offset across it. One undo step. Shapes inside a sketch have their own align buttons in the sketch panel.
- Rotate (W, edit bar, beside Move): the selection (or what is clicked next) turns around an axis clicked next, nothing turns before: an edge or line (around it), a circle or round edge (around its centre, square to it), a corner, centre or face point (Z through it; clicking that point again: X, then Y); in a sketch the click sets the point the shapes turn around (in their plane). The pointer turns it as the line tool turns a line (1° steps, Shift the angle step, drawn as the line tool draws an angle: the start and current rays in orange with an arc between them, the angle steps as orange rays while Shift is held and a moment after A / Shift A (finer / coarser), Ctrl the minimum angle; the angle at the pointer); a click keeps it; digits typed go into the panel's Turn ° (then the pointer leaves it; scrub its label). The panel at the top of the view: Turn °, To object, and one switch Set axis / X / Y / Z (that world axis through its point; also the keys): the axis in use lit, the others greyed, still clickable. The axis shows dashed red, its point as an orange cross. Enter or ✓ keeps it (one undo step: bodies get a new position and Rotation X° / Y° / Z°, groups a custom origin, tool bodies turn with their owner), Esc puts it back. A selected sketch shape's blue rotate handle has its line reaching in to the point it turns around (its centre, a blue dot). Not built yet: rotation rings on the move gizmo.
- Joints (J, edit bar, last; schema 13): a parent that stays (the first selected body or group, or the one clicked), the objects that move (the other selected ones, or clicked, Enter), the axis (an edge or line, or a circle's or round edge's centre, square to it; shown dashed); it is made as "Hinge n" (0–180°) and its edit panel opens. The edit panel (also from the joint icon in the list, ✎ in the joints box, Edit on its card): Hinge / Slider, Min and Max (scrubbed by their labels; changing one shows the joint there; T or To object: click a point, the moving part points at it or reaches it), Speed × (times Settings → Joint play time, 4 s first), ⇄ Invert (the other way round); Enter keeps it, Esc drops it (a new joint: removes it). The axis lies in the parent's coordinates, so it moves with the parent. A joint only places: its moving objects sit at its Now value (saved), turned or moved from where the parent is (joints on moved parents chain; a boolean's tool bodies move with their owner). Modelling happens there: moving, rotating and drawing on faces count in the moved place, and bodies pulled from a sketch on a moving part join its motion. A part put into a group beside the joint's other part makes that group the part. The object list shows the joint icon beside the eye (the parent's blue); hovering it outlines in the list what stays (blue) and what moves (orange), and in the view what moves; dragging it onto another object hands that one its place (a new parent keeps the axis where it is in the world). The edit panel's ▶ Play shows the joint once from Min to Max without keeping where it stops. T for Min / Max measures from the moving part's direction at 0: its own X / Y / Z nearest to where its middle lies (a lid's middle sits a little above its hinge, a block's beside the edge it turns on). Joints play each on their own clock; one stopping (its pose saved, everything redrawn) leaves the others where they are in their motion. A body made on another body's face counts that face in its group's coordinates (moved by its joint), so it rides along exactly; while a joint plays, the sketches on moving parts stay where they were until it stops. The joints box at the bottom right of the view: per joint its name (edited in place) and range (grey), ✎, ▶ / ❚❚ plays from where it is to the max and pauses (it stays there), Repeat plays back and forth smoothly instead, the slider and the Now field follow it and set where it is (either stops it). A body in two joints, or joints and groups that place each other in a circle, are reported there and left still.
- Revolve (U, edit bar, beside Extrude): closed shapes (the selected ones, the selected sketch's, or the outline clicked next) turned around an axis clicked next (a sketch line, construction lines too, or a body edge lying in their plane; shown dashed while hovering): a new body at once, its Angle (360° first) typed or scrubbed in a panel at the top of the view, Enter keeps it, Esc leaves nothing. Its card: Revolve add / cut, the angle, its sketch (linked: editing the shapes changes it). The sample's "Revolve me" sketch is a vase's half outline beside its axis.
- Work planes (left toolbar, beside Sphere; schema 20, `workFrame` in src/doc/workplane.ts): made on what is selected (a sketch: its plane; an edge picked with Alt-click: a plane along it, facing up as far as it can, turning around the edge), else on a face clicked (empty space: the base plane facing you): a green, half see-through plane. Its panel (also ✎ in its card): Offset along its normal (T: a clicked point's distance, to calculate on: `/2` for halfway), Turn ° around its axis (Set axis: an edge or line; none: its own x line through where it was made), Points: clicked points it passes through (one: it turns around its axis to it; two: through both, its normal as near as it was; three: through all three; a fourth drops the first; empty space ignored; Esc stops picking), Clear; the panel shows Turn only while fewer than two points are set. Its card: name, Offset, Turn, each point's X / Y / Z (× leaves it out), Draw on it, Delete. Drawing tools hovering it draw on it; sketches on it follow it.
- Thread (edit bar; schema 16): click the round face of a hole or a shaft (found from the face itself: its axis from its normals, the circle its points lie on, its length): a real thread is cut into it from its end nearest the click, all along it. A panel: Metric / Imperial (as the document's units first) and the size list (ISO 261 / 262 metric coarse and fine, ASME B1.1 UNC / UNF; the size fitting the face first: a shaft by its diameter, a hole by its tap drill), which fills Ø and Pitch (both editable), and the length (T: to a point), live. The ISO basic profile (ISO 68-1; Unified threads share it): 60° flanks, 5/8 H deep, the root P/4 wide on a shaft, P/8 at a hole's major diameter, running out one pitch past both ends; built from flat faces, 36 per turn (OpenCascade's booleans with swept helical surfaces fail now and then). Its card: hole / shaft, Metric / Imperial, size, Ø, pitch, length.
- Bulge (edit bar, beside Loft; in sketch mode too; schema 18, `bulge` in src/kernel/build.ts): a face swells out smoothly (or dents in), its rim kept and sharp, or closed sketch shapes become a dome body of their own (named "Bulge n"). What is selected (a face picked with Alt-click or last clicked on a selected body, a sketch's selected shapes) or what is clicked next (a face, or a sketch shape's outline). Its peak is a point from the face's middle (body-local X / Y / Z, 10 mm out first; a round face: half its radius out, towards the click): its part across the face is the height (negative: a dent, no limit), the rest moves it over the face; on a round face its part along the axis is where it swells most, its distance from the axis less the radius how far (out: a shaft swells, a hole widens). Fullness -4 (a cone) to 4 (flat topped), 0 a pillow, 1 a dome (first); kept to that range. A flat face is replaced by OpenCascade's smooth filling (BRepOffsetAPI_MakeFilling) over its outer edges and the body sewn again (a face with holes: the dome glued on along the face, the holes drilled on through it). The heights come from a pillow: Poisson's equation solved on a 60-cell grid over the face (0 at the rim), one smooth field without creases, rounded towards corners; its top moved to the peak (each point reads the field nearer the middle the higher it is), shaped by the curve, and passed to the filling on 48 lines from the rim to the peak; a round face is turned again with one smooth B-spline profile. A panel: X / Y / Z (T or the target button after Z: the height to a clicked point, the rest kept; a round face: its distance from the axis) and Fullness (kept to -4..4 in the field too); live, one undo step; Esc leaves nothing. Its card: the same fields, ✎ opens the panel again (Esc puts it back). Shell and booleans work on bulged bodies. Sample: "Domed plate". Not yet: bulging round faces sideways, faces that are neither flat nor round.
- Linked copies (schema 15): Duplicate and paste (in their move fields: no Copy; Linked while the copied bodies are there, not after ⌘X), copy-move (Linked shows once Copy is ticked; off first), Mirror (a box while picking the face) and Pattern (remembered this session) have a Linked checkbox; for Duplicate it changes the copies at once. A linked copy shares its source's steps: its card shows them (editing them edits the source and every copy), its own steps (a mirror) come after; position, turn, name and colour stay its own. Shape edits on any of them go to the shared steps, so all change: pushing a face, a new fillet (dragged edges or + Fillet), thread, bulge, shell, resizing or deleting a finish. A copy of a linked copy links to the same source; Unlink in its card gives it its own steps; deleting a source passes its steps to its first copy. Boolean tool bodies cut a linked copy as they sit by the source. The object list puts linked copies in their source's group under it (folded first, a chevron to open; copies in other groups stay there, marked with the link icon); each copy's link button unlinks just it (its own steps; it leaves the others in the list; Unlink in its card the same); every edit on any of them goes to the shared steps (booleans: the tools move by the source as they lay by the copy; Cut: all are cut, B only for the clicked one); the source's link button breaks the links (asked first): each copy gets all the steps, and the source and its copies go into a new group of its name, in its place. Sketches are not linked yet (moving a sketch moves its shapes, which a shared sketch would need placed apart).
- Pattern (edit bar): copies of the selected bodies (or those clicked next, Enter), live, one undo step. Grid: X / Y / Z pcs (whole numbers, scrubbed in 1s; typed decimals round when the field is left; negative: the copies go the other way), the spacing fields just X / Y / Z (on hover: X gap, or X overall): the gap between copies along each (or, with Overall, the whole length from the first copy's start to the last one's end: switching fills it in from the gaps, and back), T or To object on a gap / Overall field: the last copy's far side ends at the clicked point along that axis, and a turn per copy (each further copy turns that much more around its middle). Around: an axis clicked first (as Rotate's: an edge, line, circle or point; Set axis picks another, the values kept), Count (with the original, whole) over Angle ° (360: evenly all the way round), Turn copies (else they only move). Grid and Around switch in the panel.
- Mirror (edit bar; in sketch mode too): selected sketch shapes across a line or edge clicked next (it has to lie in their plane): mirrored copies beside them. Else the selected bodies (or those clicked next, Enter) across a face clicked next (empty space: the base plane facing you): mirrored copies as new bodies, "… mirrored", each ending in a Mirror step (it runs after the finishes, so they keep their picked edges).
- Offset / Shell (edit bar; in sketch mode too): selected sketch shapes get new outlines a distance outside them (negative: inside; rectangles keep their corner radius grown, regular polygons stay regular, polygons are mitred, a line moves to its left), the distance live in a panel. A body (selected, or clicked next) is hollowed: the faces clicked one by one are left open (none: closed, hollow inside), Enter, then the wall thickness (inside the body, live). Shell is a step in the body's card (Wall, faces open); fillets and chamfers listed before it are made first, so the walls follow them inside too. Its icon: a double-walled box, open at the top.
- Sweep (edit bar, beside Revolve): a line or shape outline clicked (the path, any sketch), then the outline of a closed sketch shape (the profile): a new body, the profile's middle on the path's start, square to it, corners mitred. Linked to both. The sample's "Sweep profile" circle and "Sweep path" line make a pipe.
- Loft (K): the outlines of closed shapes clicked in order, one per sketch; from the second on the new body shows through them; Enter keeps it, Esc leaves nothing. Linked to the shapes (moving or editing a sketch changes it); its card says which sketches and has Ruled (straight between the shapes, else smooth). The sample's "Loft base" and "Loft top" sketches are a square and a circle 40 mm above it.

Faces never depend on booleans, so a cutter drawn on the target's face works; real cycles are reported.

Clicking within 8 px of a sketch outline (or of a circle's centre dot) picks that shape. Values keep their expressions where they can (`a` moved by 5 becomes `a + 5`).

- Sketches go on any flat face: an extrusion's end face or straight side face (the sketch follows that face when the body changes), else a fixed plane where the face was. New sketch (S) with a face clicked on a selected body uses that face right away.

A body with a sketch (one it extrudes, or one on its face) gets a sketch button in its row that opens that sketch. In sketch mode with shapes selected, the right column shows only those shapes.
- Groups: the object list shows each level's groups and bodies in their places (`order`; without one groups first, then bodies); the ▸ / ▾ in a group's row, where bodies show their colour, folds it, and so does a plain click on the row (it also selects the group; not the click on its name that starts renaming); drag rows (with the rest of the selection): the upper or lower half of a row puts them before or after it (into its group; this also reorders the list), the middle of a group row into the group, the Objects header to the top level; any depth (moving before or after numbers that level's places anew). The group tool (toolbar, as in incase) groups the selection (⌘G; nothing selected: click objects, Enter) into a group named after the first object picked, in that object's place in the list, or, with a group selected, ungroups it (⇧⌘G): its contents move to its parent and stay where they are. A group's eye hides its contents without touching their own eyes. Its panel (⚙ or select it): name, delete (with its contents), origin: the parent's, or a custom point and turn (degrees around X, then Y, then Z) its contents count from: changing it moves and turns them all, while inside the group they are edited unturned; booleans, face pulls, sketches on faces, snapping and sections follow the turn. Moving objects between groups keeps them in place (their own turn stays as it was, so a body moved into a turned group turns with it).
- Import (arrow button in the top bar, or drop a file): a STEP file (.step / .stp) becomes a real solid body: the kernel reads it (in mm, as the file says; big files take a while, each is read once per session), the file's text is stored in the document; booleans, fillets, sketches on its faces and exports work on it. Neither format has a unit: a small dialog asks for it (mm / cm / m / in) or for its size along X, Y or Z (the others follow, proportional), the body showing at each size as it is set; guessed as cm and z up for Autodesk / Fusion OBJ files, else mm (OBJ turned from y up to z up). Tests check a 50 mm cube from Fusion as STL, OBJ and STEP (`src/io/fixtures`). Meshes move, group, colour and render like any body; booleans, face pulls and exports do not work on them yet.

The sample document has two test pieces for it (one chamfered edge, one rounded edge). A size set below 0 turns a fillet into a chamfer and back (`-3` → `3`, `-ply` → `ply`, longer expressions as `-(…)`).

## CAD goals

What a basic, fully working CAD tool still needs, most important first (revolve, loft, sweep, shell, mirror, pattern, linked copies, threads, rotation, work planes and STEP export are built, 2026-11-02).

1. **Arcs in sketches**, tangent arcs too: rounded profiles without approximating them.
2. **Dimensions and basic constraints** (fixed length, parallel, perpendicular, equal, coincident): truly parametric sketches.
3. **Edge references that survive edits** (the biggest risk for finishes).
4. **Measure** between two things (distance, angle); the Info panel measures one.
5. **Holes as a feature** (counterbore, countersink) and a **2D drawing / PDF** of a part.
6. **Draft** on faces.
7. **Rotation rings** on the move gizmo.
8. **Flatten** a body (its whole recipe as one fixed solid, kept as STEP data; booleans' tool bodies can go then; lossy, only ⌘Z undoes it).
9. **Any body as a cutter** in the Cut tool (now: planes, sketch lines and shapes, balls, cylinders).

Create a **simple, scale-accurate 2D SVG** from the attached reference image for import into CAD / 3D software.

Use **only the attached image**. Do **not** search online, use datasheets, or add dimensions from external knowledge.

The goal is **mechanical reference geometry**, not visual reproduction.

Requirements:

- Use any dimensions explicitly shown in the image as the primary scale reference.
- Infer all other dimensions proportionally from the image.
- Keep everything in **metric millimetres**.
- Make the SVG physically scaled so that CAD software imports it at the intended real-world size.
- Use simple black outlines on a white background.
- No shading, textures, perspective, decorative detail, dimension arrows, or photographic detail.
- Use as **few SVG objects as practical**.

Prioritize these features:

- overall outer dimensions
- outline/profile of the main object
- corner radii
- mounting holes
- screw-hole locations
- pin/header locations
- repeated hole or pin spacing
- connectors, switches, sockets, and other parts protruding beyond the main body
- other mechanically important features

For repeated pins, pads, holes, or headers:
- detect whether they appear to use a regular raster/pitch
- infer that pitch from the drawing where possible
- preserve the correct number and approximate locations
- if a standard-looking pitch can be inferred directly from the image, note the estimated pitch, for example `~2.54 mm`

For mounting holes:
- include their estimated diameter and centre positions
- note the corresponding **metric screw size**
- if the screw size is explicitly stated in the original drawing, reproduce it normally, e.g. `M3`
- if it is only inferred from the image, mark it clearly as approximate, e.g. `~M3`, `~M2.5`, etc.
- never present an inferred screw size as exact

For connectors or components that stick out beyond the main outline:
- make them separate SVG objects
- simplify each one to a rectangle, rounded rectangle, circle, or similarly basic shape
- do not draw internal connector details unless mechanically necessary

For pins and labels:
- label only the most important pins/functions if they are clearly readable or inferable from the supplied image itself
- do not invent pin functions
- keep labels in a separate SVG group so they can easily be removed before CAD import

Accuracy rules:

- Clearly distinguish between:
  - dimensions explicitly shown in the image
  - dimensions estimated proportionally
  - dimensions inferred from repeated geometry/pitch
- Do not silently use outside knowledge.
- If something is uncertain, make a reasonable proportional estimate rather than omitting it.
- Prefer mechanically useful approximate geometry over visual detail.

SVG construction:

- output a **real SVG file directly**, not a raster image
- use millimetres for width/height where possible
- use a matching `viewBox`
- give important objects sensible IDs such as:
  - `main-outline`
  - `mounting-holes`
  - `header`
  - `usb-port`
  - `power-port`
- group optional text labels separately
- keep the SVG clean and easy to edit

- the dimensions taken directly from the image
- the most important estimated dimensions

### Design notes

- Shift does the opposite of a tool where that makes sense.
- Editing 2D and 3D objects uses the same tools wherever possible (booleans work on both, for example). There is no special sketch mode: sketches can be drawn at any time.
